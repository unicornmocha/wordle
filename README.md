# Wordle Clone 🎮

I built this project to practice frontend web development and game logic using HTML, CSS, JavaScript, and jQuery. The goal was to recreate a simplified version of Wordle while improving my understanding of DOM manipulation, keyboard input handling, grid layouts, and game state management.

This project is currently an active work in progress, with the core gameplay loop already functioning end-to-end.

---

## Features

- Play a 5-letter word guessing game inspired by Wordle.
- Dynamic tile coloring based on correct and incorrect guesses.
- Keyboard input and backspace handling.
- Win and lose game states implemented.
- On-page game messages and refresh/restart functionality.
- Grid-based game board built with HTML and CSS Grid.

---

## How to Run

Clone this repository:
```bash
git clone https://github.com/unicornmocha/wordle
```
Open the project folder and launch:
```bash
index.html
```
No additional installations or dependencies are required beyond a modern web browser.
